Enviar reporte de comportamiento sospechoso

El formulario permite preparar un reporte, previsualizar imágenes o videos y descargar un archivo JSON para revisión.

Selecciona imágenes o videos. Máximo recomendado: 10 archivos.

¿Cómo funcionará cuando tenga servidor?

En GitHub Pages esta página es estática: puede previsualizar archivos y crear el reporte, pero no puede almacenarlos de forma permanente por sí sola.

1. Envío

El usuario adjunta evidencias y descripción.

2. Revisión

El administrador revisa el caso antes de publicarlo.

3. Estado

En revisión, archivado o publicado como reportado.

4. Historial

Se conserva fecha, evidencia y actualizaciones.

Para activar subidas reales

Conecta este formulario a un servicio como Supabase, Firebase, Cloudinary o un servidor propio. Nunca publiques automáticamente una acusación: todos los envíos deben quedar pendientes de revisión.

Lo que todavía haría falta

La estructura ya está preparada; estas serían las siguientes mejoras.

Panel administrador

Aprobar, rechazar, editar y archivar reportes.

Base de datos real

Guardar perfiles, estadísticas, imágenes y videos.

Formulario conectado

Subidas reales con límites, antivirus y moderación.

Dominio propio

Una dirección profesional como wrdatahub.com.
